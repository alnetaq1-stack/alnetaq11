# النطاق العربي 6 — Elite Cinematic Website

موقع عربي RTL متجاوب لمركز متخصص في سيارات موبار، مع واجهة فيديو سينمائية وحركات تمرير متوازنة.

## المزايا
- فيديو خلفية في واجهة الموقع مع صورة poster بديلة، تشغيل صامت ومتكرر وبدون عناصر تحكم مزعجة.
- زر لإيقاف/تشغيل الحركة، ودعم إعداد تقليل الحركة في نظام الزائر.
- ظهور تدريجي للأقسام والبطاقات عند التمرير، مع انتقالات خفيفة.
- قائمة جوال، نموذج حجز يجهز رسالة واتساب، وروابط الأقسام.

## بيانات المركز المضمّنة (يرجى التحقق قبل النشر)
- واتساب: +966 53 292 1615
- الموقع: صناعية العاصمة – مخرج 28 – الرياض
- العلامات: Dodge, Chrysler, Jeep, RAM, SRT

## النشر
1. فك ضغط الحزمة.
2. ارفع `index.html` و`styles.css` و`script.js` إلى جذر الاستضافة.
3. تأكد من السماح بتحميل ملفات MP4 من مصدر الفيديو الخارجي أو استبدل رابط الفيديو بملف محلي تملكه.
